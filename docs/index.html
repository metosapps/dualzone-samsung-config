Know before you start

Dual means one additional instance.

DualZone uses a work profile, not unlimited virtual phones. Device restrictions, an existing managed profile, and individual apps can affect compatibility. Some apps will not work in a work profile.

Removing the work profile deletes its apps and data. Export important vault files before clearing DualZone's data or uninstalling it. Importing a file into the vault does not remove its original.
