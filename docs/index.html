Good to know

A second space.
Not unlimited copies.

DualZone uses Android's built-in work profile. A compatible device and supported apps are required.

Visit help & compatibility →
How many copies can I create?

This edition provides one additional instance of a supported app, alongside the original in your personal profile. It does not create three or more instances of the same app.

Will it work with every app?

No. App policies, Samsung device settings, Android restrictions or an existing managed work profile can affect compatibility. DualZone does not bypass third-party account restrictions.

What should I back up first?

Removing the work profile deletes its apps and data. Export important vault files before clearing DualZone's data or uninstalling. Importing a file into the vault leaves the original in place. The vault is not a cloud backup.
